### Project Description
This project delivers a comprehensive Data Analytics and Machine Learning framework to classify and segment telecommunications customers into four distinct service tiers: **Basic Service**, **E-Service**, **Plus Service**, and **Total Service**.

By evaluating key customer demographic parameters—such as tenure, income, age, marital status, and education—this analysis identifies core drivers behind customer subscription choices and provides actionable business recommendations to optimize targeted marketing and upselling strategies.
